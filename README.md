# Arduino Basics

## Overview

This repository contains a collection of my beginner Arduino projects created while learning the fundamentals of Arduino programming and electronics.

Each folder demonstrates a different component or programming concept that I practiced during my learning journey.

---

## Projects

| Project | Description |
|---------|-------------|
| LED Without Delay | Blink LEDs using `millis()` instead of `delay()`. |
| Button and LED | Control LEDs using a push button. |
| Servo Test | Test different servo motor angles. |
| LCD Display | Display text on a 16×2 LCD screen. |
| Seven Segment Display | Display numbers on a seven-segment display. |
| Joystick Control | Control LEDs using joystick directions and its built-in button. |

---
